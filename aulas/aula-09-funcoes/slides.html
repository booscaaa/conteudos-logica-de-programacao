Problema

Por que usar funções?

sentiment_dissatisfied
Sem funções — código repetido
escreva("============")
escreva("Nome: Ana")
escreva("============")
escreva("Nome: Bruno")
escreva("============")
// E se precisar mudar a linha?
Repetição → difícil de manter e corrigir
check_circle
Com funções — limpo e reutilizável
linha()
escreva("Nome: Ana")
linha()
escreva("Nome: Bruno")
linha()
// muda só em 1 lugar!
Código organizado, reutilizável e fácil de corrigir
lightbulb  Funções seguem o princípio DRY — Don't Repeat Yourself (Não se repita). Escreva uma vez, use quantas vezes precisar.
Conceito

O que é uma função?

Uma função é um bloco de código com nome próprio.
Você o define uma vez e pode chamar (executar) quantas vezes quiser.

Chamada
somar(4, 7)
→
Função executa
a = 4, b = 7
retorne 4 + 7
→
Resultado
11
tag
Tem nome
É identificada por um nome único. Você a chama pelo nome sempre que precisar.
input
Pode receber dados
Os parâmetros permitem passar valores para a função processar.
output
Pode devolver resultado
Com retorne, a função entrega um valor de volta para quem a chamou.
Sintaxe

Função sem parâmetros e sem retorno

Também chamada de "procedimento"
DECLARAÇÃO (escrever a função)
funcao exibirSeparador() {
  escreva("-------------------")
}
CHAMADA (executar a função)
funcao inicio() {
  exibirSeparador()   // ← chama aqui
  escreva("Nome: João")
  exibirSeparador()   // ← reutiliza!
  escreva("Nome: Maria")
  exibirSeparador()   // ← e de novo!
}
info  No Portugol Studio, as funções ficam dentro do bloco programa { }, fora do inicio(). A ordem de declaração não importa.
Sintaxe

Função com parâmetros

funcao saudar(cadeia nome, inteiro idade) {
  escreva("Olá, ", nome, "!")
  escreva("Você tem ", idade, " anos.")
}

funcao inicio() {
  saudar("João", 20)   // nome="João", idade=20
  saudar("Maria", 17)  // nome="Maria", idade=17
  saudar("Pedro", 25)  // nome="Pedro", idade=25
}
COMO OS PARÂMETROS FUNCIONAM:
Chamadanome (cópia)idade (cópia)Saída
saudar("João", 20)"João"20Olá, João! … 20 anos.
saudar("Maria", 17)"Maria"17Olá, Maria! … 17 anos.
saudar("Pedro", 25)"Pedro"25Olá, Pedro! … 25 anos.
info  Os valores passados na chamada são copiados para os parâmetros. Alterar o parâmetro dentro da função não altera a variável original.
Sintaxe

Função com retorno

DECLARAÇÃO COM TIPO DE RETORNO
funcao inteiro somar(inteiro a, inteiro b) {
  retorne a + b
}

funcao real media(real x, real y) {
  retorne (x + y) / 2.0
}

funcao logico ehPar(inteiro n) {
  retorne (n % 2 == 0)
}
USANDO O RETORNO
// em variável
inteiro r = somar(4, 7)    // r = 11

// direto na expressão
escreva(somar(4, 7))    // 11

// em condição
se (ehPar(8)) {
  escreva("é par")
}
Tipo na frente: inteiro, real, logico, cadeia.
Sem tipo = sem retorno (procedimento).

Parâmetros

Como os parâmetros funcionam

funcao dobrar(inteiro x) {
  x = x * 2          // modifica x LOCAL
  escreva("Dentro: ", x) // exibe 20
}

funcao inicio() {
  inteiro numero = 10
  dobrar(numero)        // passa cópia de 10
  escreva("Fora: ", numero)  // ainda 10! não mudou
}
MEMÓRIA EM inicio()
numero = 10
nunca é alterado
⟶ cópia ⟶
MEMÓRIA EM dobrar()
x = 10 → 20
existe só dentro da função
warning  Passagem por valor: o Portugol copia o valor para o parâmetro. Modificar o parâmetro dentro da função não altera a variável original.
Retorno

Como o retorne funciona

CÓDIGO
funcao inteiro maximo(inteiro a, inteiro b) {
  se (a > b) {
    retorne a  // ← encerra AQUI
  } senao {
    retorne b  // ← ou AQUI
  }
}

funcao inicio() {
  inteiro r = maximo(10, 7)
  escreva(r)  // 10
}
PASSO A PASSO
1
inicio() chama maximo(10, 7) — execução pula para a função.
2
a = 10, b = 7. A condição 10 > 7 é verdadeiro.
3
retorne a → devolve 10. A função encerra imediatamente.
4
Execução volta para inicio(). r = 10.
retorne faz duas coisas: devolve o valor e encerra a função.

Cuidado

Erros comuns com funções

error
Tipo de retorno errado
// ERRADO: declara inteiro mas retorna real
funcao inteiro div(real a, real b) {
  retorne a / b  // ← real, não inteiro!
}

// CORRETO:
funcao real div(real a, real b) {
  retorne a / b
}
warning
Esquecer o retorne
// ERRADO: declarou retorno mas esqueceu
funcao inteiro somar(inteiro a, inteiro b) {
  inteiro r = a + b  // calculou...
  // mas não retornou!
}

// CORRETO: adicionar o retorne
  retorne r  // ← não esquecer!
call_missed
Número errado de argumentos
funcao somar(inteiro a, inteiro b) {…}

// ERRADO: faltou um argumento
somar(5)        // ← só 1 de 2 valores

// CORRETO:
somar(5, 3)  // ← 2 argumentos ✓
check_circle
Regras de ouro
✓ Sem retorno: omitir o tipo antes do nome
✓ Com retorno: colocar o tipo antes do nome
✓ O tipo do retorne deve bater com o declarado
✓ Número de args = número de parâmetros
✓ Tipos dos args devem ser compatíveis
