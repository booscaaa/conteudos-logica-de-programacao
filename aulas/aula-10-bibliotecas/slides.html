lightbulb  Bibliotecas são como ferramentas especializadas: alguém já construiu, testou e disponibilizou. Você só precisa usar.
Conceito

O que é uma biblioteca?

Uma biblioteca é uma coleção de funções prontas que você pode incluir no seu programa e usar sem precisar implementá-las.

calculate
Matematica
Raiz, potência, abs, arredondamento, trigonometria
text_fields
Texto
Maiúsculo, tamanho, subCadeia, substituir, concatenar
swap_horiz
Tipos
Conversão entre inteiro, real, cadeia e lógico
build
Util
Número aleatório, pausa, caixa de diálogo, limpar console
info  No Portugol Studio, as bibliotecas são embutidas — você não precisa instalar nada, só incluir no topo do arquivo.

Estratégia

Quando usar cada biblioteca?

M

Matematica — operações com números

Quando precisar de raiz, potência, logaritmo, trigonometria ou arredondamento. Ex: calcular hipotenusa, IMC, juros compostos.

T

Texto — manipulação de cadeias

Quando precisar formatar texto, comparar sem diferenciar maiúsculas/minúsculas, extrair partes ou contar caracteres. Ex: validar CPF, formatar nome.

Ti

Tipos — conversão de dados

Quando precisar mudar o tipo de um valor. Ex: leu uma cadeia do usuário mas precisa operar como número; quer montar uma mensagem com números.

U

Util — aleatoriedade e interface

Quando precisar de números aleatórios (jogos, sorteios), pausar a execução ou exibir diálogos. Ex: jogo de dados, adivinhação.

lightbulb  Você pode incluir todas as bibliotecas ao mesmo tempo — elas não conflitam entre si.

Avançado

Combinando múltiplas bibliotecas

inclua biblioteca Matematica --> mat
inclua biblioteca Texto      --> txt
inclua biblioteca Tipos      --> tip
inclua biblioteca Util       --> util

programa {
  funcao inicio() {
    // Sorteia uma nota (Util)
    inteiro n = util.sorteia(0, 10)
    // Calcula raiz (Matematica)
    real r = mat.arredondar(mat.raiz(tip.real(n)), 2)
    // Monta mensagem (Texto + Tipos)
    cadeia msg = txt.concatenar("Nota: ", tip.cadeia(n))
    escreva(txt.maiusculo(msg), " | Raiz: ", r)
  }
}
util.sorteia
Gera número aleatório
mat.raiz + tip.real
Converte e calcula
txt.concatenar + tip.cadeia
Monta e formata texto
