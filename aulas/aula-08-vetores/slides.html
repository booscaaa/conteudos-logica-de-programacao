Conceito

O que é um vetor?

Pense em um vetor como uma fila de caixinhas numeradas.
Cada caixinha guarda um valor e pode ser acessada pelo seu número (índice).

notas[5]

tag
Tipo único
Todos os valores devem ser do mesmo tipo: inteiro, real, cadeia…
pin
Índice começa em 0
A primeira posição é sempre índice 0. O último é tamanho − 1.
straighten
Tamanho fixo
O tamanho é definido na declaração e não pode mudar durante a execução.
Sintaxe

Declarando um vetor

Formas de declaração
COM TAMANHO FIXO (posições não inicializadas)
inteiro numeros[5]      // 5 inteiros, índices 0 a 4
real temperaturas[7]   // 7 reais, índices 0 a 6
cadeia nomes[3]       // 3 textos, índices 0 a 2
COM VALORES INICIAIS (tamanho inferido)
inteiro pares[] = {2, 4, 6, 8, 10}
real notas[] = {7.5, 9.0, 6.0, 8.5}
cadeia dias[] = {"Seg", "Ter", "Qua"}
info  O tipo na frente (inteiro, real, cadeia) define o tipo de todos os elementos. Todos devem ser do mesmo tipo.

Operações Comuns

Soma e Média de um vetor

real notas[] = {7.0, 9.5, 6.0, 8.5, 5.0}
real soma = 0.0

para(inteiro i = 0; i < 5; i++) {
  soma = soma + notas[i]
}

real media = soma / 5.0
escreval("Média: ", media)

Encontrar o maior valor

para(inteiro i = 1; i < 5; i++) {

Cuidado

Erros comuns com vetores

error
Índice fora do limite
inteiro v[5]  // índices 0..4
v[5] = 10   // ← ERRO! não existe [5]
v[-1] = 3   // ← ERRO! índice negativo
Vetor de 5 posições → índice máximo = 4
all_inclusive
Condição errada no para
inteiro v[5]
// ERRADO: i <= 5 → acessa v[5]!
para(i = 0; i <= 5; i++) { }

// CORRETO: i < 5 → acessa v[0]..v[4]
para(i = 0; i < 5; i++) { }
pin_drop
Esquecer que começa em 0
inteiro v[] = {10, 20, 30}

// Primeiro elemento é v[0], não v[1]
escreval(v[0])  // → 10 ✓
escreval(v[1])  // → 20 (não 10!)
check_circle
Regra de ouro
Para um vetor de tamanho N:

✓ Índice mínimo: 0
✓ Índice máximo: N − 1
✓ Condição no para: i < N

Vetor [5]: índices 0, 1, 2, 3, 4
